# Freelancer Invoice & Client Management System (Frontend Only)

A responsive, complete frontend application built with **React + Vite + Tailwind CSS + Lucide Icons**, implementing all 11 modules from the detailed flowchart:

1. **Home Page (Public)** - Hero, Features, About, Contact form, and Role-based Registration.
2. **Login Flow** - Credential validation with Freelancer & Client routing and 1-click Demo logins.
3. **Freelancer Dashboard** - 6 Overview Metric cards (`Total Clients`, `Total Projects`, `Total Revenue ₹`, `Completed Projects`, `Pending Payments`, `Total Expenses`) + Management modules.
4. **Client Dashboard** - Overview cards (`My Projects`, `My Invoices`, `Pending Payments`, `Project Status`) + Actions (`Find Freelancer`, `Send Project Request`, `View Invoices`, `Payment History`).
5. **Project Workflow** - Client request → Freelancer Accept/Reject → Work in Progress → Completed → Generate Invoice → Paid.
6. **Invoice & Payment Flow** - Line items builder, Tax %, Discounts, PDF Print/Export, and Manual payment entry (UPI, NEFT, Card, Cash).
7. **Reports & Analytics** - Monthly cash flow bar chart, Net Profit summary, and PDF export.
8. **Notifications** - Alert drawer with badge count, overdue alerts, payment confirmations, and deadline reminders.
9. **Interactive Chatbot** - Floating guide assistant for Registration, Projects, Invoices, and Payments.
10. **Profile & Settings** - Profile editing, bank/UPI details on invoices, password change, and ₹ INR currency.
11. **Logout Flow** - Session clearing and redirect to Home page.

## Running Locally

```bash
# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
